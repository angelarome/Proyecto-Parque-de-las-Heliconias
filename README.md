# Heliconias Report

Heliconias Report es una aplicación web de reportes desarrollada para el Parque de las Heliconias.
El sistema se conecta a una base de datos en Supabase que recibe información desde otras páginas
del parque, donde se registran datos de visitantes.

La aplicación permite consultar y generar reportes estadísticos a partir de esta información,
incluyendo filtros por género, edad y otros criterios relevantes.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Supabase

## Funcionalidades
- Conexión a base de datos Supabase
- Consumo de datos registrados desde otras aplicaciones del parque
- Generación de reportes por género y rangos de edad
- Visualización clara de la información para apoyo en la toma de decisiones

## Trabajo en equipo
Proyecto desarrollado en equipo.
Mi rol incluyó el desarrollo de la interfaz, la conexión con Supabase y la generación de reportes.
